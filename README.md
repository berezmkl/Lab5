## Lab 5 — Git Flow та GitHub Actions

### Мета
Ознайомлення з моделлю Git Flow та налаштування CI-конвеєру за допомогою GitHub Actions для автоматичного запуску модульних тестів.

### Структура проєкту
├── SonarNet/                 
├── SonarNet.Tests/          
└── .github/
    └── workflows/
        └── unit-tests.yml  
### Запуск тестів

```bash
dotnet restore
dotnet test
```

### Висновки

У ході виконання лабораторної роботи було опановано модель розгалуження **Git Flow** та відпрацьовано повний цикл роботи з гілками: **feature**, **release**, **hotfix**, **develop** та **main**.

Було виконано підготовку та публікацію релізу **v1.0**, реалізовано hotfix-процес для виправлення критичної помилки, а також налаштовано **GitHub Actions** (`unit-tests.yml`) для автоматичного запуску **xUnit**-тестів при push у гілки Git Flow. Підключений тестовий проєкт `SonarNet.Tests` успішно пройшов усі CI-перевірки у віддаленому репозиторії.
